## Title
Adoption of React Native, NestJS, and Python Microservice Architecture for FitFlow Redesign

## Status
Approved

## Context
FitFlow experienced an app rating drop from 4.6 to 3.8 stars due to slow logging, lack of personalization, and retention loss. The redesign requires high cross-platform UI responsiveness, camera-based food recognition (CV), AI adaptive workout planning, and strict GDPR compliance.

## Decision
- **Frontend:** React Native (TypeScript) with Hermes engine and New Architecture
- **Core API Backend:** NestJS (Node.js) for business logic, progress tracking, and WebSockets
- **AI Microservice:** Python (FastAPI) for ML workout recommendations and CV nutrition models
- **Database:** PostgreSQL (with Row-Level Security) & Redis Cache
- **Real-Time & Auth:** Firebase FCM & Supabase Auth (JWT)

## Consequences
- **Positive:** Over 85% code reuse across iOS and Android, sub-second CV model response, robust health data isolation via RLS.
- **Negative:** Requires managing multi-service inter-process communication (REST/gRPC) and Docker orchestration.
