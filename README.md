# FitFlow Redesign

A human-centered mobile application redesign featuring AI-powered workout plans, instant nutrition tracking, and community features.

## Tech Stack
- **Frontend:** React Native (TypeScript)
- **Backend:** NestJS (Node.js)
- **AI Microservice:** FastAPI (Python)
- **Database:** PostgreSQL & Supabase Auth
- **Real-Time:** Redis & Firebase FCM

## Project Structure
- `frontend/` - Cross-platform mobile app
- `backend/` - Core REST & WebSocket services
- `ai-service/` - Machine learning & computer vision pipelines
- `docs/` - Architecture diagrams, ADRs, and evaluation matrices
